# Medical Arts Dispensary of Ottawa 🏥

A modern, responsive multi-page website for **Medical Arts Dispensary of Ottawa**, a specialized long-term care pharmacy serving senior care communities across Ontario, Canada.

---

## 🌐 Live Pages

| Page | Description |
|------|-------------|
| `index.html` | Homepage — hero, mission, services overview, and network |
| `about.html` | About the dispensary and team |
| `who-we-serve.html` | Target clients and care environments |
| `our-services.html` | Detailed breakdown of all pharmacy services |
| `contact.html` | Contact form and dispensary information |

---

## 🛠️ Tech Stack

- **Pure HTML5 & CSS3** — no frameworks or build tools required
- **Google Fonts** — Poppins & Nunito for clean, modern typography
- **CSS Custom Properties** — centralized design tokens for easy theming
- **Responsive Design** — mobile-first layout with CSS Grid and media queries
- **Glassmorphism UI** — frosted-glass navigation with `backdrop-filter`

---

## ✨ Features

- Sticky glassmorphism navigation bar
- Animated hero section with floating gradient shapes
- Responsive CSS Grid layouts (2-column → 1-column on mobile)
- Hover micro-interactions on cards, buttons, and nav links
- Service cards with icon highlights and lift animations
- Partner/logo showcase section
- Clean dark-navy footer with CTA
